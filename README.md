# 合同生成工具

用于从 Excel 产品明细生成采购合同和销售合同 Word 文件。

## Windows exe 构建

GitHub Actions 会在推送到 `main` 分支或手动触发时构建 Windows 可执行文件。

构建产物位置：

```text
Actions -> Build Windows EXE -> Artifacts -> 合同生成工具-windows
```

## 运行方式

下载并解压构建产物后，把真实的 `公司数据.xlsx` 放到 exe 同目录，然后运行：

```bat
合同生成工具.exe 产品明细表.xls
```

也可以指定配置文件、Sheet 或输出文件夹：

```bat
合同生成工具.exe 产品明细表.xls --config config.yaml --sheet 现货产品明细表
合同生成工具.exe 产品明细表.xls --output D:\合同
```

不传 `--output` 时，运行过程中窗口会依次询问税点、预付款比例、融资时长、销售订单模板版本和保存位置：

```text
请输入税点百分比 (如9表示9%，默认9):          ← 直接回车用默认值
请输入预付款百分比 (如30表示30%，默认30):      ← 直接回车用默认值
请输入融资时长/天 (默认90):                  ← 直接回车用默认值
请选择销售订单模板版本：
  1 = 旧版（老客户，默认）                    ← 直接回车或输入 1
  2 = 溢价版（新客户，含溢价金额）             ← 输入 2
请输入 1 或 2 (直接回车 = 1):
请输入费率百分比 (如5表示5%，默认5):          ← 仅溢价版会问
请选择合同的保存位置：
  1 = 程序同目录（默认）                      ← 直接回车或输入 1
  2 = 自定义文件夹（弹出选择窗口）              ← 输入 2 后弹窗选文件夹
请输入 1 或 2 (直接回车 = 1):
```

## 销售订单的两个版本

公司有两套销售订单模板，按客户区分，生成时在窗口里选：

| 版本 | 模板 | 用于 |
|---|---|---|
| 旧版 | `templates/销售合同模板.docx` | 老客户 |
| 溢价版 | `templates/销售订单溢价版.docx` | 新客户 |

溢价版多一个变量 `{{溢价金额}}`，算法：

```text
溢价金额 = 垫款总金额 × 费率 ÷ 360 × 提货期限天数
垫款总金额 = 采购合同总金额 − 预付款
```

费率在窗口输入（默认取 `config.yaml` 的 `premium_sales.financing_rate`，当前 5%）。
溢价版金额按千分位显示（`39,195.51`），重量/件数不带千分位。
两种版本的文件名不同（溢价版带 `销售订单溢价版-` 前缀），不会互相覆盖。

溢价版由 `config.yaml` 的 `premium_sales` 节配置，`product_table.template_row_index` 为 2
（该模板有两个表头行）。

## 数据安全

真实业务数据不会入库：

- `公司数据.xlsx`
- `产品明细表.xls`
- 输出合同文件
- 本地日志和缓存文件

exe 不内置公司数据，运行时从当前目录或 exe 同目录读取 `公司数据.xlsx`。
